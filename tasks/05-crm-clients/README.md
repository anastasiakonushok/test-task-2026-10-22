# 05. CRM: дубли клиентов

## Запуск

Из папки `tasks/05-crm-clients`:

```text
php find_duplicates.php
```

Отчёт: `report/duplicates-report.txt` (и вывод в консоль).

Проектирование обращений и защита от дублей: `05-design.md`.

## Логика скрипта

- Нормализация: УНП (ровно 9 цифр), email (нижний регистр, без пробелов), телефон (последние 9 цифр), название (без ООО/ЧУП/ИП и кавычек).
- В группу попадают карточки с одинаковым УНП, с одинаковым email, если УНП не противоречат, и с одинаковыми телефоном и названием, если УНП не противоречат.
- Два заполненных разных УНП не объединяются, даже если совпали телефон или название. Такие пары выводятся отдельно.
- Главная карточка: есть УНП, затем больше обращений, затем более ранняя дата создания.
- CSV не изменяются, слияние не выполняется.
