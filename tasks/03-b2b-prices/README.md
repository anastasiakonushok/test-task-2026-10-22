# 03. Расчёт цен B2B

Запуск из папки `tasks/03-b2b-prices`:

```text
php check.php
php run.php K-001 B-101
```

`check.php` не меняет `var/cache.json`. Описание пяти обращений — в `03-prices.md`.

## Принятое решение по отсутствующей цене

Если в выгрузке из 1С нет цены того типа, который назначен клиенту, другая цена не подставляется: для этого клиента цена товара недоступна. Иначе дилер может купить по рознице или по чужому опту, и сумма разойдётся с учётом. В реальном проекте это правило нужно сверить с ценовой политикой компании: если бизнес решит показывать замену, это должно быть отдельное согласованное правило, а не тихий запасной вариант в коде.
