# 01. Сопоставление заказов маркетплейса с 1С

Учебное задание. Данные выдуманы.

## Запуск

Из папки `tasks/01-orders-1c-sync`:

```text
php reconcile.php
php bugs/OrderTotal.php
```

- `reconcile.php` — сверка `data/orders.json` с `data/nomenclature_1c.csv`.
- Результат: `report/report.csv`, лог `var/reconcile.log`.
- `bugs/OrderTotal.php` — расчёт суммы заказа и НДС (см. `bugs/ORDER-TOTAL-FIXES.md`).

Нужен PHP 8.1+.

## Решения

**Связка:** `items[].sku` в заказе = колонка `Артикул` в CSV (пробелы обрезаю, регистр не важен).

**Цена 1С:** убрать пробелы тысяч, запятую заменить на точку. Сравнение с допуском 0,01.

**Остаток:** уменьшаю виртуальный остаток по мере обхода заказов в JSON (как резерв под отгрузку). Отменённые заказы (`cancelled`) в 1С не отправляю и остаток по ним не списываю.

**Дубль заказа:** повтор того же `id` (например `MP-24009` дважды) — вторая запись в отчёт, в 1С не дублировать.

**Дубль артикула в 1С:** для `TS-1017` в CSV две строки — в лог пишу предупреждение, для сверки беру **первую** строку.

**Отменённые:** только пометка в отчёте, без проверки остатка.

**Пустой заказ / битая строка** (нет цены, нет qty): в лог и отчёт, скрипт не падает.

Источник заказов сейчас файл; массив заказов можно подставить из HTTP без смены логики сверки.
